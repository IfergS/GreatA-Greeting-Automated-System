# ⚡ XAMPP MySQL - Quick Start (5 Minutes)

## 🚀 Fast Setup

### **1. Install & Start XAMPP**
- Download: https://www.apachefriends.org/
- Install XAMPP
- Open XAMPP Control Panel
- Click **"Start"** next to MySQL ✅

### **2. Create Database**
- Open: http://localhost/phpmyadmin
- Click **"New"** → Database name: `greeta_attendance` → **"Create"**

### **3. Run App**
```bash
flutter run
```

**That's it!** 🎉

---

## ✅ Default Settings (Already Configured)

- **Host:** `localhost`

## 🐛 Quick Fixes

**MySQL won't start?**
→ Check if port 3306 is in use
→ Restart XAMPP Control Panel

**Can't connect?**
→ Make sure MySQL is "Running" (green) in XAMPP
→ Check database `greeta_attendance` exists
